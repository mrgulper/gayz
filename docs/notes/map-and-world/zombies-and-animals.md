# Zombies and animals

Split out of the old `map-and-world.md` on 2026-11-13 (word for word, oldest first). Add new notes at the end.

## Animals, held blocks, sky top bar, bridges (2026-10-18, second batch)

- PlayAnimals.js (`s.animals`): open world only (`bm.world.active`), stepped from BuildSurvival.update while playing. Wild ones spawn in groups SPAWN_MIN..SPAWN_MAX from `tryMode.pos` (so also while spectating), despawn past DESPAWN; pets follow `bodyPos()`. Shots reach them via `shoot()` (only when no zombie was hit) and PlayThrow; Use goes through `_tryUseFromCamera` -> `animals.use()`. Meat is an ITEMS entry (heal) dropped with `PlayDrops.spawnItem` (a sprite of the item icon). Animals are deliberately NOT MOB_HEIGHT (real animal sizes) - that rule is for standing/humanoid mobs.
- `BuildTryMode.drawHand(renderer, type, inPlay)`: it used to return whenever try mode was active, so inventory blocks were never drawn in hand while playing. Held cubes with see-through textures use alphaTest + DoubleSide.
- TopBar: weather + game time parts from `BuildSky.topBarLook()`; colors via `--tb-night`/`--tb-storm`/`data-weather` with color-mix in play-pause.css.
- Bridges: deck at `sea + BRIDGE_CLEARANCE + 2`, nothing but whole piers lower than `sea + BRIDGE_CLEARANCE + 1` (water fills up to y = sea). City tracks still cross water on a plank deck at y = sea (OpenWorld) - not changed.
- Auto Quality (`_updateEditorResScale`): view distance goes down before resolution, resolution comes back before view distance.

## Sun-burning zombies, cave zombies, own meat per animal, 30 creatures, huge meat-eaters, scary hunters (2026-10-30)
- Sun (BuildSurvival): `_sunny()` = sky `_now === 'clear'` and `nightAmount() < SUN_NIGHT_MAX`. `_updateZombie` re-checks twice a second: sunny, not `_inCave`, `_skyAbove(x, y + 1, z)`, not `_wetAt` -> `zb.sunlit`, taking SUN_BURN_DPS (6, not scaled by player damage) with the fire effect. Spawning is unchanged (Gaymi picked "burn, but still spawn"). Applies to every zombie, skeleton and monster, Map Editor play too if its sky is a clear day.
- Caves: `_inCave` = below `world.under.bottomAt - 1`. `_spawnZombie` skips CAVE_SPAWN_CHANCE (0.45 go ahead) of cave spots; ones made get CAVE_HP_MULT 1.8 / CAVE_DAMAGE_MULT 1.6 and `zb.cave`.
- Meat: `PlayInventory.addAnimalMeat` registers `meat_<kind>` items (key, animalKey, icon: meat / poultry / fishMeat / bugMeat); `itemName(id)` fills `{animal}`. Names: MEAT_NAMES in PlayAnimals (beef/pork/mutton/chicken/venison/rabbit), swimmers + birds `invRawOf`, else `invRawMeatOf`. Old `meat` item still works for saves.
- CreatureKinds.js: 30 kinds (17 real, 13 made-up, made-up ones Legendary) from `PLANS` exported by WildAnimalKinds. Yeti/sasquatch 2 blocks tall.
- DinoKinds BULK: 7 big meat-eaters x1.45-1.6, extra WIDE 1.35, thighs/jaw/chest boxes, health x2 (T. rex ~7.7 tall).
- Scary: every `hunts` kind gets `scary`: colours x0.8, angry brows + scar (faceTexture), teeth (snoutTexture), unlit red eye boxes + fang boxes (_build). Looks only.
- Test: buildmode "sun-burning zombies, cave zombies, own meat drops, new creatures, scary hunters". buildmode + docs 74/74.

## Golden/Diamond zombies, Photo Mode, death jokes (2026-10-30)
- ZombieNames.js `ZOMBIE_SHINES` (gold 1/200 x10 coins, diamond 1/1000 x50), rolled on top of the tier (`rollZombieShine`, `_spawnZombie`). A shiny zombie is NOT batched: `shineBody` gives the template's parts their own cloned materials (tint + emissive, `glowShineBody` per frame from `_sizeZombieTags`; red flash handled there too), `zombieShineFx` adds halo/sparkles/ring (+ sky beam for diamond), all `userData.shared`; `_removeZombie` disposes `shineMats`. Synced as snapshot `sh` and credit `shine` (api/_lib/servers.js `ZOMBIE_SHINE_IDS`). Kill/assist coins x `shineCoins`; stats `goldKills`/`diamondKills`; sounds `goldZombie`/`diamondZombie` in Audio SPECIAL_SOUNDS.
- Photo Mode: PlaySpectate `enter({ photo: true })` (pause menu `#play-pause-photo-btn`). `frozen` (photo and not on a server) makes BuildMode.update skip `survival.update`. `body.play-photo` hides everything but `#scene`, `#play-photo-ui` and phone stick/jump/crouch (play-pause.css). Click/P/Enter/shutter -> `bm._photoPending`; BuildMode.render saves the canvas right after drawing (no preserveDrawingBuffer) and skips the gun.
- You Died joke: `_lastBiter` set on a bite/bloater burst, used within DEATH_JOKE_BITE_MS by DeathJokes.js `deathJoke(name)` -> `#build-play-over-joke`. i18n `deathJoke1..8` ({name},{job}), `deathJob1..24`, `deathJokeAlone1..6`.

**Catching and Team Battles (2026-10-31, Gaymi's own idea; picked "weaken, then throw a trap" and "you control one creature").** `PlayCatch.js` (owned by BuildSurvival as `s.catcher`): the `catchTrap` item (PlayInventory `ITEMS`, `trap: true`; `START_TRAPS` in the last hotbar slot on `inv.reset`, `CATCH_TRAP_CHANCE` in Loot Chests) is thrown through `inv.useHeld()` -> `catcher.throw()`, flies like PlayThrow and rolls `catchChance(health, max, tier, boss)` on the first zombie / wild animal it touches. Caught: zombie removed like a lost one (no kill credit, but `_toSpawn--` so the wave still ends), animal `animals.remove()`, then `Creatures.addCreature`. On a server a guest's trap waits on the spot (`tr.wait`, `_waiting` queue) and sends `PlayNet.queueCatch(id)` (a hit with `catch: true`); the host's `_applyRemoteHits` hands it to `catcher.hostCatch`, which rolls against the real health and answers with `queueCatchResult` -> server `players/{pid}/caught` (`cleanCatch` in api/_lib/servers.js) -> the guest's `catcher.remoteResult`, which keeps the creature. Answers match waiting traps oldest-first. `Creatures.js`: the collection in localStorage `gayz-creatures` (`{ list, team, wins, losses, nextId }`, cleaned on every load - it can come from a shared save file); battle stats are computed from kind/tier (`stats()`), never stored. `TeamUI.js`: homepage Team panel (`#team-panel`, `#team-btn`, route slug `team`). `TeamBattle.js`: its own overlay (`#team-battle`) with its own WebGLRenderer, made per battle and disposed on close; animals reuse `PlayAnimals._build` with a fake `{ B: 1, bm: null }` survival (shared geometries - don't dispose them), zombies are a simple blocky 2-block-tall model with per-battle materials (safe to flash). Tests: `tests/team.spec.js`.

**Catching v2, Pets tab, mob health bars (2026-10-31, later the same day).** Gaymi: "they dont needa be weak to catch", picked "chance, rarer = harder": `catchChance(tier, boss)` is `BASE_CHANCE` (0.85) x `RARITY_MULT` x `BOSS_MULT`, health no longer counts. `TEAM_SIZE` is 10 ("make it 10 slots"); a battle stands teams in rows of `ROW` (5) and `botTeam(target, size)` makes a Wild Team as big as yours. The Team page moved into Inventory > Pets (`#team-page`; no homepage Team button, no `/team` URL). `MobHealthBars.js` (`s.hpBars`): a canvas-sprite bar under the name tag of any zombie or wild animal whose health dropped, for `SHOW_S` seconds - it watches health each frame, so new mob kinds just go in its `mobs()` (Gaymi wants every future mob to have one).

## Quick wins: Blood Moon, zombie cosmetics, death replay, photo filters (2026-10-31)
- `BloodMoon.js` (owned by BuildSurvival as `bloodMoon`): rolled once a night (`CHANCE`, from `FROM_WAVE`, homepage games with the Cycle sky) by the host/alone in `_updateWorld`; ends when the night lifts after being dark (`_dark`, so a daytime `start()` in tests lasts). `mult` doubles `_toSpawn` (on start + `_startWave`), `aliveCap`, spawn speed and `_earn`. `BuildSky.bloodMoon` (+ eased `_blood`) reddens sky, lights and moon; sent as `skyState().b`. `syncLook()` (everyone, every frame) toggles `body.play-blood-moon` (red edge, play-pause.css) and the start/end messages.
- Zombie cosmetics: `FunnyZombies.HAT_KINDS` now includes the players' propeller/chicken hats; `zombieCape(id)` (1 in `CAPE_EVERY`) uses `Cosmetics.makeCape`. Killing one wearing a locked cosmetic -> `_wornByZombie` message once per kind per run.
- `DeathReplay.js` (`survival.replay`): `record()` every playing frame alone (20 Hz, last `SPAN` s: my pos/yaw, each zombie's group pos/rot); `_die` (not won, not net) calls `start(show, joke)` and shows the You Died card only after. Plays at `SLOW`: moves zombie groups, shows `tryMode._body`, `applyView` orbits the camera in BuildMode.render (no hand drawn). `body.play-replay` hides the HUD. Skip: click/tap, Space/Enter/Escape (window capture listener). Tests call `s.replay.stop()` after dying.
- Photo filters: `PhotoFilters.js` colour matrices; live = SVG `feColorMatrix` via `canvas.style.filter`, saved = same matrix on the copied 2D canvas (`_lastPhoto`). Post to Gallery (`postPhoto`): prompt title, JPEG <= `POST_MAX`, `postToGallery(kind: 'photo')`. Gallery `photo` kind (tab, `PICTURE_KINDS`, no Use button). **Firestore rules allow `kind in ['character','map','photo']` - must be re-pasted in the Firebase console.**

## Zombie Book + Infection mode (2026-10-31)
- **Zombie Book** (`ZombieBook.js`, Inventory > Zombie Book): `BOOK_IDS` = zombie, boss, the 4 skeletons, every monster kind but the spider. `BuildSurvival._makeZombie` calls `meet()` (skeletons only once their model loaded, else they're drawn as plain zombies) - first meet pays `BOOK_COINS` (shop coins), the last one `BOOK_DONE_COINS`. Saved in `gayz-zombie-book` (Cloud Save carries it). Pictures: a throwaway renderer like the weapon thumbnails; the plain zombie (`buildTexturedCharacter`) is in skin pixels (32 tall) so it's scaled to 2 like the others, or it lands past the camera's far plane. Unmet = `filter: brightness(0)`.
- **Infection** (`Infection.js`, mode `infection` in `PLAY_GAME_MODES` + `NO_ZOMBIE_MODES`): whoever `runs` (solo/lobby, or the server host) keeps the round, moves the bots (`TOTAL` minus real players, only added/removed while waiting) and checks tags from everyone's synced spots. Host sends `inf` (servers.js `cleanInf`, only on `mode: 'infection'` servers); guests' stun shots go as hits `s<id>`. Lobbies/Invite Friends create the server with the game's mode (`serverMode` in ServerBrowser.js) and joiners take `net.mode`. The first zombie is held `HEAD_START_S` (everyone spawns in one spot - without it the host tagged the joiner instantly). Infected: `tryMode.speedMult` up, green `#infection-vignette`, `shoot()` returns false. Other players who are infected wear a zombie body (`p.zbody`) over their own.
