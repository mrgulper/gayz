# Block textures (HD, real-life ground)

Split out of the old `map-and-world.md` on 2026-11-13 (word for word, oldest first). Add new notes at the end.

- **Realistic HD block textures and skeleton enemies (2026-10-16, Gaymi: "sharper, more realistic block textures ... and real 3D models").** *Textures:* every 16x16 painter in `BlockTextures.js` still sets the layout, then `BlockTexturesHD.js` (`hdPixels`, pure pixel maths, no DOM) turns each face into a 64x64 texture: Scale2x/EPX twice so staircases become smooth lines (colours within `EPX_SIMILAR` count as equal; `ground` style skips EPX - it melts noise into puddles - and upscales smoothly), an edge-preserving 5x5 bilateral blur (lookup-table weights), shared tileable grain noise read at a per-block offset, and lighting from a height map (relief from the top-left + cavity darkening), tuned per material in `HD_STYLES` (`hdStyleOf` picks: stone, brick, ground, wood, bark, metal, cloth, smooth, glow, leaves, glass, liquid). All ~311 faces take ~0.9 s of CPU, so **they're made in a Web Worker** (`BlockTexturesHD.worker.js`, started by `prepareHdTextures` from the BuildMode constructor): until it answers, `blockFaceCanvases` hands out the 16x16 paintings; then `BuildMode._applyHdTextures` repaints the chunk atlas in place (`BlockChunks.refreshAtlas`, same slots so no UV changes) and gives every other block material a *new* texture from its HD picture (`hdCanvasFor`; never swap a texture's image for a bigger one - the GPU copy can't change size). The atlas is 4096 wide with 64px tiles on computers (~28 MB with mipmaps, height not rounded to a power of two) and 32px tiles on touch devices (~7 MB); magnification is linear now (block textures aren't pixel art any more). Icons read the face's real size (`src.width`), never `S`. Test: "block textures turn HD once the worker is done" (a tile with >300 colours can't be 16x16 art). *Skeletons:* `SkeletonModels.js` loads KayKit Character Pack: Skeletons (Kay Lousberg, CC0, `public/models/skeletons/` + its LICENSE, credited in Credits > 3D Models) - four bodies sharing one rig, so the 8 kept clips (`CLIPS`) live only in `skeleton_minion.glb`; trimmed with gltf-transform (unused animations' channels *and samplers* disposed, or their keyframes stay in the file - 4.8 MB -> ~150 KB per body), texture 1024 -> 128 (5.6 MB -> 87 KB GPU), meshopt. Lambert materials like the block world, own clones per skeleton (hit flash). `BuildSurvival`: from `SKELETON_FROM_WAVE` (PlayRules.js) each non-boss spawn is a skeleton with `SKELETON_CHANCE`, kind stats in `SKELETON_KINDS` (hp/speed/damage multipliers); it rises (`SKELETON_RISE`, no moving/hitting meanwhile), walks/runs/idles by speed (`_skeletonGait`), punches, flinches, and on death `_skeletonCorpse` keeps the body playing its fall, lying `SKELETON_LIE`, then sinking (`_boneCorpses`). They aren't in the zombie instanced batch (each is its own skinned mesh, ~9 draws). The snapshot carries `k` (kind) and `api/_lib/servers.js cleanZombie` keeps only the four known kinds. Test: "skeletons rise, fight, sync and die". `3D_ASSET_OVERHAUL.md` was written for the old Map 1 (its targets are deleted) - see its status line.

## Real-life ground: grass + dirt (2026-11-08)
Gaymi: "make every block like grass or leaves real ... not just big blocky blocks" - edit with blocks, see real shapes. Answers: top 3 levels only (`realShape` in `LEVEL_LOOK`: realistic 0.7, ultra 0.85, irl 1; the auto device pick decides who gets it), placed/broken blocks reshape live (chunk rebuild), looks real but collision stays whole cubes, first batch grass + dirt only.
- `RealGround.js`: every lattice point (corner where 8 cells meet) gets one move from those 8 cells only - toward the ground on outside corners, toward air on inside ones, 0 on flat - plus world-position noise bumps/wobble. Shared corners/edges move identically, so no cracks. A corner touching anything not grass/dirt/air/plant (planks, water, torch, slab...) is pinned (w = 0), so real ground meets other blocks exactly.
- `BlockChunks._realCell`: 3x3 grid per visible face, normals/shade/AO from the lattice (no per-face seams), brightness from soft noise (`realTint`, not per block), grass tops turned a random quarter. A grass side whose front cell has ground under it (a 1-block step) uses the grass top picture - slopes look green, cliffs stay dirt.
- Followers: `GrassTufts` (near tufts via `realTopLattice`/`realTopPoint`), plants (`_plant` lift), pebbles, dig crack (`realFaceGrids` in `BuildTryMode._digCrackShape`), `lumpyTopPoints`.
- Cost: full Map 3 rebuild ~0.20s vs ~0.15s on In Real Life (M4). 

### Batch 2: leaves + trunks (2026-11-08)
Gaymi's answers: trunks round and filling the block (corners look empty, you still bump the full cube), logs side by side each stay round (log cabin), bushy top with leafy fringe, every leaf kind (`/leaves$/`, bamboo too) and log kind (`/log$/`, stripped + mushroom log).
- Leaves (`_realLeafCell`): own lattice cache (`_latticeFn('leaf', _leafKindOf)`): leaves and logs = REAL, air/plants = AIR, the rest pins. `LEAF_LOOK` = bigger bumps/wobble, `K_LEAF` = 1. Only faces against non-leaf blocks are drawn, so leaf kinds touching join. 1-2 "clumps" per face: two crossed double-sided leaf cards tipped out from the surface, lit with the surface normal (no dark backs). Cutout buffer, so the wind sway still applies (position-based, stays joined).
- Logs (`_realLog`): 12-sided cylinder, 2 rows, radius `logRadius` (0.45-0.5, bark noise from world y + column, so stacked logs line up), each quarter shows its side picture, ring caps where no log/solid block covers the end, darker foot on the ground. Skipped when all 8 side neighbours are solid non-logs. Logs no longer hide neighbour faces (`hides()` in `_build`, and in `_realCell`) so their empty corners show the block behind, not a hole. Ground lattice still pins at logs.
- Crack: `realFaceGrids` follows the crown for leaves; logs keep the cube crack. `lumpyTopPoints` returns null for logs.
- Test: `buildmode.spec.js` "real-life trees". Cost: full Map 3 rebuild +~50ms (2374 leaves, 363 logs; headless).

### Batch 3: stone/rocks (2026-11-08)
Gaymi's answers: every stone-ish block (bricks/polished/smooth too), "a bit of both craggy and smooth boulders", rock melts into grass/dirt.
- `REAL_ROCK` / `NOT_ROCK` (RealGround.js): ids with stone/cobble/granite/.../obsidian or ending in `ore`; not slabs/stairs/walls/fences/buttons/plates/lamps/doors/`*block`, gadget stones (echo/weather/sauna), or emissive blocks. `info.real` + `info.rock`; `_kindOf` -> `ROCK`, which the ground lattice treats as ground (so rock and dirt share corners = melt together).
- Lattice records are now `REC` = 9 floats: [8] = rock fraction round the corner. Rock corners round 30% less (`ROCK_ROUND`). realPoint interpolates it (`rf`) and blends the dirt bumps into `rockD` (craggy ledges + ridges vs smooth boulders, drifting by world noise seed 50), bumps 1.6x bigger. Out: `rock`, `grain` -> `rockTint`.
- Speed: noise slopes are analytic now (`vnoiseD`, one call instead of 4 finite differences - grass/dirt got cheaper too), rock jitter comes from one noise's slope. Full Map 3 rebuild on In Real Life ~2x the no-rock cost (e.g. 0.81s vs 0.41s with ~34k rock blocks, mostly cave walls; simple 0.16s; headless). Streaming stays budgeted (LAZY_BUDGET_MS).
- Test: `buildmode.spec.js` "real-life rock".

### Batch 4: water (2026-11-08)
Gaymi picked all four: soft shoreline, depth colour, real rolling waves, waterfalls. (My question wrongly said waves were Ultra-only - Realistic/Ultra/IRL already had `waves` 0.03/0.06/0.1.) All gated on `realShape` > 0 (`fx.realWater` uniform).
- Soft shore: `_kindOf` returns AIR for water, so banks and lake beds round off under it (they used to pin). `_realWaterTop` draws the top as a small grid that reaches `SHORE_REACH` (0.45) under any opaque neighbour side (dipped 0.06, out of sight), so the water meets the rounded bank. The old shader corner-curve/sand trick is off when real.
- `aWater` attribute (water meshes only): (depth in blocks, splash). Depth = average of the 4 columns round each corner (water cells down, capped 8; non-water = 0; reach-under vertices 0) -> shader mixes green shallows (alpha 0.3) to dark blue (0.9) and foam where depth < ~0.1-0.17. Splash = 1 if any of those 4 columns has water above (a waterfall lands) -> churning white. Splash -1 marks reach-under vertices: the vertex shader keeps them still (cancels the small waves too) so crests never lift water over a bank. Plain tops push (-1, 0) = old look.
- Swell: vertex shader adds two long sines (amp `uAmount`, x0.25..1 by corner depth), slope passed as `vSwell` to tip the normal. Sparkles in the fog_fragment block. Side faces (vTop 0) get downward-scrolling streaks (`vWy`).
- Test: `buildmode.spec.js` "real-life water". Cache key `waves-sky-ripples-real`.

### Batches 5-10: Gaymi's answers (2026-11-08, all "your picks")
Same rules as batches 1-4: top 3 levels only, live reshape, whole cubes underneath, corners touching other blocks pinned, small measured speed cost. Ores, stone bricks, sandstone, polished/smooth stone were already done in batch 3. One PR per batch. Gaymi stopped after batch 5 to save usage - batches 6-10 are for a fresh session. All 10 built by 2026-11-08.
- **5 Soft ground** (melts into grass/dirt/rock): sand, red sand, gravel, mud, packed mud, clay, moss, mycelium, podzol, coarse dirt, rooted dirt, dirt path, soul sand, soul soil, crimson/warped nylium, plain terracotta. Sand = gentle rippled dunes, smoother than dirt. Gravel = lumpy with small stones poking out. Mud = flat, soft, a bit shiny wet.
- **6 Snow, ice, lava:** snow = soft rounded drifts, smoother than dirt, slightly sparkly. Ice (ice, packed, blue) = smooth glassy rounded slabs that stay see-through. Lava = like the water batch: soft edges, glowing dark crust that drifts, bright cracks, lava falls.
- **7 Nature extras:** crimson/warped stems round like trunks. Cactus, pumpkin, melon, hay bale = round shapes inside the block (like logs: empty-looking corners, full cube to bump). Mushroom/wart/coral blocks + sculk = soft bumpy blobs that join, like treetops. Amethyst, magma, glowstone, ancient debris, raw ore blocks = rock look.
- **8 Wood builds** (all planks, wood, bookshelf, barrel, crate, crafting table, timber frame, thatch, roof/slate shingles): flat with softened edges, wood colour drifting across planks; thatch shaggy and straw-like.
- **9 Stone and metal builds** (brick, nether/mud/quartz/prismarine bricks, quartz, purpur, all concrete, coloured + glazed terracotta, plaster, asphalt, metal, iron, gold, all copper, diamond/emerald/lapis/netherite/coal/redstone blocks): metal and gem blocks sharper edges than stone, shinier.
- **10 Soft and see-through:** wool soft and pillowy (puffier than option A); glass gets thin rounded frame edges, clearer middle; honey and slime rounded jelly blobs.
- **Man-made rule (8-10), option A "one solid wall":** same-kind blocks join smoothly, only the outside edges of the whole build get slightly beveled, faces stay perfectly flat and straight so builds line up. Two different kinds touching = sharp clean line. Draw flat parts with few triangles (cities have a lot of surface).
- **Stay plain cubes on purpose:** gadget/machine blocks (TNT/C4, jukebox, note block, furnace, target, sponge), every lamp/glow light (sea lantern, froglights, lanterns, redstone lamp), and slabs/stairs/fences/doors.
- Design idea for 8-10 (mine, not built): per-face 4x4 grid at s,t in {0, b, 1-b, 1} only when an edge/corner moves (else 1 quad); edge points move from the 4 cells round that cube edge (exactly 1 same-kind filled, rest air = b/2 inward on both axes), corners take the per-axis biggest of their edges' moves, face insides stay flat; normal at moved points = -move (rounded look). Gloss can ride on `aEdge` as a negative value (batch 5 does this for mud).

### Batch 5: soft ground (built 2026-11-08)
- `REAL_GROUND` widened; `LOOKS` = rock, sand, gravel, mud, snow (snow slot reserved for batch 6). `lookOf(id)` (clay = mud, terracotta = rock), `info.look` / `info.lookKind`; `_kindOf` returns the look's kind (4 + index). `REC` = 8 + LOOKS (13); slot 8 + i = fraction of that look round the corner, `LOOK_ROUND` per look.
- `realPoint`: pure dirt/rock keeps the old fast path; any soft fraction mixes each look's bump (`sandD` curving ripples ~1.5 blocks apart, top-facing only; `gravelD` half-block lumps; mud/snow one broad swell) by fraction, less sideways wobble for smooth looks. `out.gloss` (mud 0.55) goes out as a negative `aEdge`; the sun-glint shader adds `max(-vEdge, 0)` to glossy.
- Gravel: up to 3 pebbles per block (45% each, `_pebble` salt). Grassy-top slope rule now covers mycelium, podzol and nylium (`GRASSY_TOP`).
- "bumpy block tops" test now runs on Detailed (no natural block stays a plain cube on the top 3). Test: "real-life soft ground"; 40x40x3 field rebuild 184ms mixed vs 185ms dirt (headless).

### Batch 6: snow, ice, lava (built 2026-11-08)
- `REAL_GROUND` + `snow|ice|packedice|blueice`; `LOOKS` gained `ice` (REC 14, slot 13). Snow = the shared broad swell (SNOW_BUMP 1), LOOK_ROUND -0.12, gloss 0.15; ice = ICE_BUMP 0.15, wobble x0.15, LOOK_ROUND 0.2, gloss 0.9. Plain `ice` is transparent: `info.real` lets it in, and `_build` sends real cells with `!solidDraw` to `out.clear` (alpha kept).
- Snow sparkles: the solid shader's sun-glint block adds hashed glints (cells of 1/26 block, blinking with the view direction, near only) where own gloss (-aEdge) is 0.06..0.4 and the picture is light (lum > ~0.7) - so mud (dark) and ice (gloss 0.9) don't sparkle.
- Lava: `_kindOf` -> AIR (banks round under it), the real top goes through `_realWaterTop` (stride-3 colours ok), lava meshes carry `aWater` too. `materials.lava.onBeforeCompile` (cache key `lava-real`, gated on `fx.realWater`): top = drifting crust noise with crack lines (noise crossing 0.5, two scales), rare open molten patches, crust where shallow, bright churning splash; sides = glowing streaks moving down with crust lumps. Everything after `emissivemap_fragment`; vertex shade clamped to 1 (glow sources lit the crust brown) and the crust albedo kept tiny (~0.015) because the top levels' sun turns even 0.045 brown.
- Test: `buildmode.spec.js` "real-life snow, ice and lava" (also renders a frame and checks no shader errors). The soft-ground test no longer lists snow as a cube.

### Batch 7: nature extras (built 2026-11-08)
- Stems: `REAL_LOG` = `/(log|stem)$/`. `roundOf(id)` (RealGround.js) -> 'log' | 'cactus' | 'hay' | 'pumpkin' | 'melon'; `info.log` now means "any round block" (all the old log exceptions - `hides`, ground face skip, lumpyTopPoints null - apply), `info.round` says which. Only `round === 'log'` joins a treetop (`_leafKindOf`).
- `_realLog` draws them all: `roundRadius(shape, a, t, ...)` / `roundHeight` (pumpkin 1 - 0.12 amt, melon 1 - 0.05 amt). `ROUND_STACKS` (log/cactus/hay) run on when stacked (cap skipped when the neighbour has the same `round`, or is a solid non-round block); fruit (pumpkin/melon) has 6 rows with tipped normals (radius slope) and always draws both ends.
- Blobs: `REAL_BLOB` (mushroom blocks, nether/warped wart, 5 coral blocks, sculk) -> `info.blob`, drawn by `_realLeafCell` on the treetop lattice with no clumps (solid buffer). `_leafKindOf`: blob = REAL, water = AIR (coral under water rounds). Blobs don't hide neighbours' faces (`hides`, ground face skip) and get `realFaceGrids` cracks.
- Rock: `REAL_EXTRA_ROCK` (amethyst, magma, glowstone, ancient debris, raw iron/gold/copper blocks) -> `lookOf` 'rock' even though they end in `block`; emissive ones stay real and `_realCell` writes them to `out.glow`. The rock test's "not rock" list swapped glowstone for sealantern. Shroomlight, jack o'lantern, sea lantern stay cubes.
- Test: `buildmode.spec.js` "real-life nature extras". Not looked at on screen yet (shapes checked by vertex positions only). "far grass, cracks on bumpy tops..." (expected > 1.02, got 0.65) failed on main too - not from this batch. Cause: clay became real ground, so on In Real Life a lone clay block is rounded (top ~0.65) and the crack follows that correctly. ### Batch 8: wood builds (built 2026-11-08)
- `REAL_WOOD` (RealGround.js): every `*planks`, wood, bookshelf, barrel, crate, craftingtable, timberframe, thatch, roofshingles, slateshingles (explosive barrel, slabs/stairs/fences/doors not). `info.wood` / `info.thatch`. Drawn in `_build`'s normal face loop (after AO), `_realWoodFace` instead of the quad; `lumpyTopPoints` -> null (flat top, cube crack).
- Bevel, option A: `woodAt` = 0 empty (air/plant), 1 wood, 2 anything else. `_woodEdge`: a cube-edge segment whose 4 cells are exactly 1 wood + 3 empty moves its points h = b/2 toward that block on both other axes (b = `WOOD_BEVEL` 0.14 x realShape, one size for every wood so edges line up). `_woodCorner`: pinned if any of its 8 cells is "other"; else per-axis union of its 6 segments' moves (opposite signs cancel). Both depend only on cells round the point -> no cracks; wood of different kinds joins the same way (the texture border is the sharp line).
- Face = 1 quad when nothing on it moves (cities: most wall stays 1 quad), else 4x4 grid at 0, b, 1-b, 1; normals at moved points = -move (rounded look). Colour = bilinear corner AO x `woodTint` (soft drift, warmer/cooler) + block light.
- Thatch: always the grid, inside points puffed out by `shag` noise, 2 loose straw cards per face, and a 7-straw fringe on side faces with nothing under the block (overhang). Cards double-sided in the solid buffer.
- Test: `buildmode.spec.js` "real-life wood builds". Cost: full rebuild with a 40x40 plank town 156-171ms -> 189-194ms (M4, dev server). Looked at on screen (headless In Real Life cabin): rounded edges, flat walls, thatch fringe.

### Batch 9: stone and metal builds (built 2026-11-08)
- `REAL_STONE_BUILD` / `REAL_METAL_BUILD` + `buildOf(id)` (RealGround.js) -> 'wood' | 'stone' | 'metal'. `info.build` (BlockChunks) = that family, but null for anything already real ground/rock (stone bricks, sandstone, plain terracotta...), transparent, inset, plant, or emissive (except redstone block, drawn into the glow buffer). `info.wood` kept for the wood test/thatch.
- Same option-A bevel as batch 8 (`_realWoodFace`, `_woodEdge`, `_woodCorner` unchanged): `buildAt` = one cell classifier per family, so a different family counts as "other" -> pinned, sharp line (brick vs planks, brick vs iron). Quartz on brick = same family -> one wall.
- `BUILD_BEVEL`: wood 0.14, stone 0.11, metal 0.05. `buildGloss` goes out as negative `aEdge` on every vertex: metal/gems 0.7, coal block 0.45, glazed terracotta 0.5, rest 0 (all above snow's 0.06-0.4 sparkle range). `buildTint`: stone brightness drift 0.93-1.03, metal 0.96-1.02, no warm/cool shift. `lumpyTopPoints` null for any build block.
- Test: `buildmode.spec.js` "real-life stone and metal builds" (measured bevel brick 0.11 vs iron 0.05, iron gloss on aEdge). Looked at on screen (headless In Real Life): rounded brick/concrete edges, tighter metal pillars, sharp brick/planks line.

### Batch 10: soft and see-through (built 2026-11-08)
- `buildOf` gained 'wool' (`REAL_WOOL` /wool$/), 'glass' (`REAL_GLASS`: glass, tintedglass, *stainedglass; panes are inset so stay out) and 'jelly' (`REAL_JELLY`: honeyblock, slimeblock). `info.build` lets transparent blocks in for `JOIN_BY_ID` families (glass, jelly - drawn into `out.clear`, alpha kept). `info.join` = what it joins with: the family, or the block id for glass/jelly (red pane vs blue pane keep both frames, honey vs slime = sharp line). `buildAt` is now `buildAt(joinKey)`, a lazily made classifier per key.
- `BUILD_BEVEL` wool 0.24, glass 1/16, jelly 0.34; `BUILD_PUFF` wool 0.05, jelly 0.07: `_realWoodFace` always uses the grid for them and pushes the 4 inner points out with normals leaning from the face middle (pillow). Gloss glass 0.85, jelly 0.75; tint flat for glass/jelly, wool drifts 0.95-1.02.
- Glass: grid lines fixed at 1/16 (= the picture's 1px frame). A side with the same glass across it (in the face's plane) reads the picture 1.5px inside (UV inset), so panes join into one; frame sides keep vertex alpha 1, the rest x0.6 (`CLEAR`, only shows on stained/tinted - plain glass's middle is alpha 0 already). Jelly insets all 4 sides (no frame at all).
- Test: `buildmode.spec.js` "real-life soft and see-through" (batch 9's notBuild list dropped tintedglass). Looked at on screen (headless In Real Life): framed window in a brick wall, puffy wool, rounded honey; two stacked honey blocks pinch a little at the seam (each face puffs on its own).
