# Panels: Profile, Friends, Quests, Inventory, Shop, Achievements

Split out of the old `ui-and-menu.md` on 2026-11-13 (word for word, oldest first). Add new notes at the end.

- **Friend List, Quests, Inventory, Global, Inspect (2026-10-10 batch).** Friends: no cap any more (`savedFriends` kept 5), each row shows the friend's `#playerId` (stored on the entry; older entries get it looked up once in `_fetchFriendPresences`), and Add a Friend takes an ID **or a name** - typing shows `#cloudsave-friend-suggestions` from `CloudSync.searchLeaderboardByName` (prefix range queries on the leaderboard `name` as typed/Capitalized/lower/UPPER - the doc has no lowercase copy and the rules aren't changed for one), Add Friend with a name sends straight away when exactly one player has it. The Status picker and that list have Old theme parchment rules (the panel's dark-ink rule had made the options black on black). Lifetime quests are Coming Soon: `QUESTS` (Quests.js) is empty and `#lifetime-quests-placeholder` shows while it is. Inventory > Character has the Market's All rarities dropdown (`_renderRarityFilter`, shared). Global's server tabs are Zombie Survival (internal `main`) / Deathmatch / Parkour / Custom. Inspect lights characters softer with no environment (`InspectViewer.setObject(..., { lighting: 'character' })` - only intensities change, never which lights exist). The Privacy Policy's top line is just "Last updated: <date>" - set it to the day its content last changed (git log -L on the section).

- **Nameplate, Levels, no selection, Design a Skin hair (2026-10-11 batch).** The player's nameplate - level box, name, `[clan]` - is one markup (`.nameplate` > `.nameplate-level`/`-name`/`-clan`) filled by `Game._fillNameplate(el)` (clan on top since the same day, no brackets - see the standing rule) above the homepage character (`#player-showcase-title`, also pre-filled by the inline script after it - set the spans there, never the title's textContent) and Inventory's preview (`#inv-skin-preview-title`); each theme styles it (bronze box + parchment/ink Crimson Text in Old, gold box + white sans in Golden). The Settings name colour/font only override it when not the default (`html.custom-name-color` / `html.custom-name-font`). Levels is Coming Soon (`.coming-soon-content`, shared with Gallery's look); the level coin sits inside `#menu-player-badge`, so the backdrop-click forwarder checks `#menu-avatar-level` first. **Nothing is selectable but text boxes, from the root:** `*` has `user-select: none` (not just html/body), `::selection` is transparent outside inputs, and Game.js cancels `selectstart`/`dragstart` outside `input, textarea, [contenteditable]`; IDs are click-to-copy (`#friends-own-id`, `#other-profile-id`), never `user-select: all`. The Add a Friend name list (`#cloudsave-friend-suggestions`) lives inside `#cloudsave-friend-row` and is `position: absolute`, so it floats over the page instead of pushing it down. Design a Skin: the result message never names a style (it lists only what the words were turned into, minus what was typed as-is); long hair (`detailPass` step 2: feminine, "long ... hair" within 3 words, or a ponytail) is painted on the torso back on **both** layers, the head's back and underside (`bottom` row 7 is the back edge) and the torso's top (row 0 is the back edge); hair-only colours (`HAIR_ONLY_COLORS`) and hairstyle words colour the hair. `window.__parsePrompt` exposes the parser for `tests/skindesigner.spec.js`.

- **Game Mode trimmed, Profile notes, Inventory/Market speed (2026-10-11 batch).** Choose Class, Save Setup / Surprise Me / Keybinds / Share (+ the Share panel, `MenuPresets.js`, the ?setup/?challenge/?viewprofile links, Class Comparison, Favorite Class) are deleted - every run is the balanced build (`settings.loadout` is always `'balanced'`, `playConfig` has no class). Game Mode's map grid only lists Map 1 (the Map Editor opens from its own nav button) and `.mode-toggle` rows have no hover highlight. Profile > Hidden has private Notes (`settings.privateNotes`, never put on the leaderboard entry - only `bio` is); the Old theme Profile is all black text with no fill behind anything (end of style.css), and `#pinned-stat-select` is an oval in both themes. Weapon pictures are saved in Cache Storage (`WEAPON_THUMBS_CACHE` - **bump it when a weapon model changes**) and only drawn fresh when Inventory's Weapons tab or the weapon picker needs them; BuildMode no longer draws its ~400 picker icons while being built in the background (only when the picker opens). The Market's listings are fetched in the background after boot and shown at once on open (no loading line). The Old theme Inspect X uses the panels' paper-corner spot.

- **Signed-out Profile is one sign-in card (2026-10-23; replaced the 2026-10-10 Sign Up / Login choice and pages, Gaymi: "delete the Sign Up and Login choice ... Show the Google button on its own, and under it more ways").** `#profile-login-gate` holds one `.auth-card`: `#auth-sub`, the Google oval `#auth-google-btn`, the "or sign up / log in with" divider, and `.auth-providers` - three round logo buttons (Steam, GitHub, Discord) in each site's own colour with white marks, forced with `!important` under `#profile-login-gate` because both themes recolour every button. Gaymi dropped Apple ($99/year), WeChat (company + yearly fee), and Microsoft, Facebook and LINE (they asked for a phone number or card to set up) - code for them was removed, not hidden. Every button carries `data-provider`; one delegated click on the gate calls `_handleCloudSignIn(provider)`. `Game._renderAuthCard()` fills the words and sets the panel title to `authWelcome` (the card has no title of its own); `_openProfilePanel` sets it back to Profile once signed in. The terms line (`authTerms`) sits under the logos. Every other sign-in button (`#friends-signin-btn`, `#server-chat-signin-btn`, `#cloudsave-signin-btn`, `#clan-signin-btn`, and the new `#market-signin-btn` / `#gallery-signin-btn`) says `signUpOrLoginBtn` ("Sign up or login with...") and opens this page; they share the oval rule at the end of `style.css` and the solid pill in `theme-clean.css`. The Market and Gallery ones sit in a `.signin-footer` bar under the scroll area while signed out (`CloudSaveUI.renderSignInFooters`, after `_authReadyPromise`, re-run on every auth change); the scroll area gives up the bar's height via `:has()` so the panel stays the standard height. Clean theme: `.auth-btn span` needs its own colour rule or the Google words vanish on the dark pill. Tests: "signed-out Profile shows Google and the other sign-ins" and "sign-in buttons go to the Welcome page" in `tests/panels.spec.js`.

- **More Zombie Survival upgrades, Inventory hitch, designer colour (2026-10-10).** 12 upgrades were added (`META_UPGRADES` in MetaProgress.js + `UPGRADE_PLAY` in PlayRules.js, which the Upgrades panel lists via `PLAY_META_UPGRADES`): swiftfoot/sprinter (`speed` -> `cfg.moveMult`), scavenger/treasureHunter (`coinBonus` -> `cfg.coinMult`, Loot Rush now multiplies it), warChest (coins), secondWind (`regen`), ammoBelt/bandolier (`ammo` -> `cfg.ammoMult`, read by `BuildSurvival._startReserve`), headhunter (`headshot` -> `cfg.headshotMult` in `shoot()`), thickSkin (`toughness` -> `cfg.zombieDamageMult`), fieldMedic (campHeal), lastStand (health + armor) - test "new Zombie Survival upgrades change the run" in tests/progression.spec.js. A new upgrade needs an entry in both tables plus its `meta*` i18n title in en/zh/hi/es. Opening Inventory the first time used to stall on `_weaponThumbnails()`'s set-up (renderer + a 256px PMREM of RoomEnvironment, all before its first `await`): it now pauses (rAF + timeout) before each heavy step and builds the PMREM at `size: 64` (4.7s -> 0.8s in software GL). Each pause also waits while a game runs with the weapon picker closed - without that the deferred set-up landed while a second player was joining and the host missed its syncs and was dropped (the two-player server test caught it). Design a Skin's Old theme `--accent` is light parchment `#e1c189` (Gaymi's swatch, was orange-brown `#b47a3c`), with dark brown rims on active/primary buttons and ink for words that used the accent. Golden Inventory weapon cards are warm brown, not navy.

- Persistent (localStorage) vs per-run state: `MetaProgress.js`, `Achievements.js` persist across runs. `companionTrainingLevel`, `companionGear`, shop purchases reset on a fresh `new Game()` but survive a same-session "restart run" click — match this precedent for any new per-run state.

- Emoji were tried once for the Achievement Showcase badges (`icon: '🩸'` etc.) and reverted before shipping - `#profile-emblem-row`'s own comment in `style.css` documents a deliberate "no-emoji UI" convention (plain colored swatches instead), and a `grep` confirmed zero emoji anywhere else in the codebase. Replaced with a `tag`/`color` pair per achievement (a short monogram like `FB`/`5N` + a hex accent color) rendered as a small colored-border swatch, consistent with the emblem picker's existing visual language. Check for a codebase-wide styling convention like this (a comment on a *similar* existing element, not just a grep for the literal thing you're adding) before introducing a new visual pattern.
